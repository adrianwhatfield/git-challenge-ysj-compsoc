# git Challenge (2026/27, Semester 1, Week 3)

This is a small challenge to get familliar with commit git commands. There are two branches in this repo `main` and  `new_feature`, the goal is to merge `new_feature` into the `main` branch. However, there is a bug in the `main` branch that needs to be fixed.

## Steps

1. Clone repo
2. Create and change to `bug_fix` branch
3. Fix bug and commit
4. Merge `bug_fix` into `main`
5. Switch to `new_feature`
6. Add user input
7. Commit your code
8. Merge `new_feature` into `main`
